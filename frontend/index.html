Project Defense & System Technical Reference

Project Summary

An intelligent carbon accounting platform that quantifies individual greenhouse gas emissions across 7 activity categories, executes dynamic linear regression on user history to forecast 7-day trajectories, and normalizes output into a Unified Green Score benchmarked against the Paris Agreement 4.1 kg/day target.

Closed-Loop Architecture

User Activity Telemetry → CO₂e Computation (IPCC / DEFRA / CEA Factors) → SQLite Storage → Behavioral Pattern Engine → Scikit-learn Trajectory Forecasting → Actionable Reduction Matrix → Benchmark Comparison.

Emission Calculation Formula

Emission (kg CO₂e) = Activity Amount × Factor • Petrol Two-Wheeler: 15 km × 0.043 kg CO₂e/km = 0.645 kg CO₂e • Grid Electricity: 10 kWh × 0.700 kg CO₂e/kWh = 7.000 kg CO₂e • Factors cited from DEFRA (UK Government GHG Conversion Factors) & CEA (India CO2 Database v20)

Machine Learning Engine

  • Trajectory Forecasting: Dynamically fits an Ordinary Least Squares (OLS) Linear Regression model directly on the user's historical daily aggregate emission totals using Scikit-learn (or browser-side fallback), avoiding rigid static lookup matrices.
  • Data Persistence: Parameterized SQLite storage (ecotrack.db) with index on (user_id, logged_at) ensuring SQL-injection immunity.
  • Resilient Offline Synchronization: Offline entries queue in local storage with integrity state and automatically flush via idempotency checks when the REST heartbeat re-establishes.

REST API Contracts

GET /api/health -> Service heartbeat GET /api/factors -> Verified & estimated emission factor registry GET /api/config -> Global benchmarks, modifier weights, limits POST /api/activities -> Inserts validated activity record GET /api/activities -> Retrieves chronological activity entries DELETE /api/activities/<id> -> Removes record by primary key GET /api/summary?days=N -> Aggregates continuous daily category totals POST /api/predict -> Fits Scikit-learn regression forecast POST /api/recommendations -> Delivers ranked reduction interventions
